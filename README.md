# Roohani - Restaurant Website Project

<b>DISCLAIMER:</b> <i>This project is intendet for educational purpose only. Any information provided or statements of any person mentioned may not be accurate or factually correct. The source of most of the data (texts and images) are the social media links mentioned on the project website.</i>

<b>Description:</b> This project is a website for a restaurant named "Roohani", a restaurant established in 2024 by Chef Nayanjyoti Saikia. It serves as a digital storefront to showcase the restaurant's ambiance and culinary offerings.

<b>Tech Stack:</b>
- Programming Languages: HTML, CSS and JavaScript
- Third-Party Service: Formspree (for form submissions)

<b>Use of AI:</b> 
- Tools used: Gemini Pro and ChatGPT (Basic)
- They are mostly used for debugging, text generation (feedback and about page) and image generation (image of the restaurant's team).

<b>Timeline:</b> The core structure was completed in the first semester mainly using CSS and HTML. As I advanced my skills, I revisited the project to significantly improve the UI/UX and add new features.
